# Архив EVM-версии

Эта папка хранит точный снимок технической модели проекта до перехода на Solana.

- Базовая сеть: Robinhood Chain / EVM.
- Газ: ETH.
- Токены: ERC-20 и Robinhood Stock Tokens.
- NFT: ERC-721.
- Торговая комиссия: Uniswap v4 hook.
- Контракты: Solidity + OpenZeppelin + Foundry.
- Frontend Web3: viem + wagmi.
- Исходный Git-снимок: `c7c2ea8`.

Документы в этой папке не являются активным техническим заданием и не обновляются вместе с Solana-версией. Они сохранены как самостоятельная основа для возможного будущего EVM-релиза.

Активная версия проекта находится в `../../ARCHITECTURE.md`, `../TECHNICAL-QUESTIONS.md` и `../SCENARIO-TESTS.md` и продолжает развиваться только под Solana.
