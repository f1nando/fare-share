# Porsche 911 — отдельный Three.js-предпросмотр

Локальный запуск из корня репозитория:

```sh
npx vite --config vite.porsche.config.js
```

Открыть http://127.0.0.1:5174/porsche.html.

Отдельная сборка:

```sh
npx vite build --config vite.porsche.config.js
```

Результат находится в `dist-porsche/`. Страница имеет собственную точку входа,
конфигурацию сборки и процедурную модель; городские сцены не импортируются.

- `src/nft/porsche-model.js` — low-poly модель по предоставленному референсу.
- `src/nft/porsche-preview.js` — студийная сцена, камера и управление.
- `src/nft/porsche-preview.css` — интерфейс предпросмотра.

Мышью или касанием можно вращать модель; колесом или жестом двумя пальцами —
приближать. Кнопки задают пять ракурсов, включают автовращение, полигональную
сетку и возвращают исходную камеру. Модель — стилизованная интерпретация
референса, а не точная CAD-копия.
