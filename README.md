# Taxi City

Полноэкранный процедурный лоу-поли город на React и Three.js. Светлые дома, парки, деревья, пешеходные переходы, обычные машины и жёлтые такси. Без управления и без backend.

```sh
npm install
npm run dev
```

Dev-сервер доступен и с других устройств в той же Wi-Fi сети: откройте `http://<IPv4 компьютера>:5173`. IPv4 можно посмотреть командой `ipconfig`. Компьютер и dev-сервер должны оставаться включёнными. Если Windows блокирует соединение, разрешите входящий TCP-порт 5173 только для локальной подсети.

`npm run build` — production-сборка в `dist`, `npm run preview` — её локальный просмотр. `npm test -- tests/world.test.js` — быстрые проверки генератора и движения.

Компонент `src/CityBackground.jsx` можно поместить в любой контейнер с заданной высотой. Размер квартала — 34 единицы; камера плавно перемещается вниз вправо. Кварталы генерируются детерминированно по координатам, невидимые удаляются. Локальный центр координат смещается вместе с камерой для сохранения точности. Геометрия повторяющихся объектов отрисовывается через InstancedMesh.

Размер квартала, полосы, интервал машин и доля такси — `src/city/world.js`. Палитра, плотность застройки, скорость и масштаб камеры — `src/city/createCity.js`.

В правом верхнем углу — сворачиваемая панель настроек: количество машин, доля и скорость такси, скорость потока, активность перестроений, размер кварталов, приближение и движение камеры. Есть пауза и сброс. Значения сохраняются в localStorage отдельно в каждом браузере и для каждого адреса сайта. Значения по умолчанию и диапазоны — `src/city/settings.js`. Чтобы встроить только фон, используйте `<CityBackground showSettings={false} />`. Настройки количества машин и размера кварталов заново создают поток; остальные применяются без перезапуска сцены.

Весь город, деревья и обычные машины — в нейтральных серых оттенках; только такси ярко-жёлтые. Трафик движется по двум полосам в каждом направлении, интервал генерации — 10,5 единицы, доля такси — 11%. На красном машины собираются с промежутками около 0,65 единицы между бамперами. После зелёного каждый водитель разгоняется с индивидуальным ускорением до своей скорости (3,4–7,6 единицы/с). Такси быстрее (13–15 единиц/с): выбирают свободные промежутки и более быстрый ряд, подстраивают скорость для въезда в узкий промежуток и быстро ускоряются после перестроения. Перпендикулярные потоки проезжают по очереди. Модели намеренно простые: домики без окон и декора, машины из нескольких блоков. Трафик декоративный; повороты на другие улицы и маршрутизация пока не реализованы. При скрытой вкладке рендер останавливается; при `prefers-reduced-motion` город статичен. Нужен WebGL 2.
