# Taxi City

Полноэкранный процедурный лоу-поли город на React и Three.js. Светлые дома, парки, деревья, пешеходные переходы, обычные машины и жёлтые такси. Без управления и без backend.

```sh
npm install
npm run dev
```

`npm run build` — production-сборка в `dist`, `npm run preview` — её локальный просмотр. `npm test -- tests/world.test.js` — быстрые проверки генератора и движения.

Компонент `src/CityBackground.jsx` можно поместить в любой контейнер с заданной высотой. На широком экране видны примерно 6 × 3,5 квартала; камера плавно перемещается вниз вправо. Кварталы генерируются детерминированно по координатам, невидимые удаляются. Локальный центр координат смещается вместе с камерой для сохранения точности. Геометрия повторяющихся объектов отрисовывается через InstancedMesh.

Размер квартала и полосы — `src/city/world.js`. Палитра, плотность застройки и такси, скорость и масштаб камеры — `src/city/createCity.js`.

Трафик декоративный: машины едут прямо по своим полосам, соблюдают дистанцию и по очереди пропускают перпендикулярный поток. Повороты и маршрутизация пока не реализованы. При скрытой вкладке рендер останавливается; при `prefers-reduced-motion` город статичен. Нужен WebGL 2.
