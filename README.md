# Taxi City

Полноэкранный процедурный лоу-поли город на React и Three.js. Светлые дома, парки, деревья, пешеходные переходы, обычные машины и жёлтые такси. Без управления и без backend.

```sh
npm install
npm run dev
```

Dev-сервер доступен и с других устройств в той же Wi-Fi сети: откройте `http://<IPv4 компьютера>:5173`. IPv4 можно посмотреть командой `ipconfig`. Компьютер и dev-сервер должны оставаться включёнными. Если Windows блокирует соединение, разрешите входящий TCP-порт 5173 только для локальной подсети.

`npm run build` — production-сборка в `dist`, `npm run preview` — её локальный просмотр. `npm test -- tests/world.test.js` — быстрые проверки генератора и движения.

Компонент `src/CityBackground.jsx` можно поместить в любой контейнер с заданной высотой. Кварталы увеличены до 30 единиц при прежнем масштабе камеры; камера плавно перемещается вниз вправо. Кварталы генерируются детерминированно по координатам, невидимые удаляются. Локальный центр координат смещается вместе с камерой для сохранения точности. Геометрия повторяющихся объектов отрисовывается через InstancedMesh.

Размер квартала, полосы, интервал машин и доля такси — `src/city/world.js`. Палитра, плотность застройки, скорость и масштаб камеры — `src/city/createCity.js`.

Весь город, деревья и обычные машины — в нейтральных серых оттенках; только такси ярко-жёлтые. Трафик движется по двум полосам в каждом направлении. Увеличенные кварталы и интервал 10,5 единицы дают примерно на 28% меньше машин в кадре относительно прежней плотной версии; доля такси 12,5% уменьшает их ожидаемое число в кадре примерно вдвое. Фактическое число зависит от кадра и фазы движения. Обычные машины плавно разгоняются и растягивают дистанцию, такси обгоняют, быстро перестраиваются в свободные промежутки и возвращаются после обгона. Машины по очереди пропускают перпендикулярный поток. Модели намеренно простые: домики без окон и декора, машины из нескольких блоков. Трафик декоративный; повороты на другие улицы и маршрутизация пока не реализованы. При скрытой вкладке рендер останавливается; при `prefers-reduced-motion` город статичен. Нужен WebGL 2.
